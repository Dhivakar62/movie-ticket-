# Luxe Cinemas — Ultra-Luxury Multiplex & Private Event Booking Platform

A pixel-perfect React implementation of the **Google Stitch** design for **Luxe Cinemas**, an ultra-luxury multiplex cinema and bespoke private event celebration platform.

---

## ✨ Features

- **Multiplex 9-Screens Experience**: Full 3x3 auditorium grid with real-time showtime chips, audio/visual formats (IMAX Laser 4K, 70mm, Dolby Atmos), and tier indicators (Premium, Gold, Platinum).
- **Interactive Multi-Tier Seat Map**:
  - Curved illuminated cinema screen visualization.
  - Row-wise seat grid (Platinum VIP Recliners, Gold Prime Club, Silver Executive).
  - Real-time seat selection with interactive status states (Available, Occupied, Selected).
- **Curated Movies & Premieres**:
  - Now Showing, Popular Screenings, and Coming Soon teaser cards.
  - Genre and category filter tabs.
- **Private Events Celebration Portal**:
  - 4 Event categories: Romantic Proposals, Grand Birthdays, Anniversaries, and VIP Private Buyouts.
  - 3 Celebration Packages: Silver, Gold (Recommended), and Platinum.
  - **Strict Cinema Schedule Enforced**: Private celebrations can only be scheduled during designated intermission break slots between active film shows. Active movie showtimes are automatically locked out.
  - Bespoke celebration add-ons (custom 4K video montage, fresh flower decor, artisan truffle cake, cinema photographer).
- **Concessions & Checkout Flow**:
  - Gourmet concessions (Golden Caramel Popcorn, Truffle Nachos, Chilled Coke, VIP Combos) with quantity steppers.
  - Simulated payment options (UPI, Credit/Debit Card, Net Banking).
  - Voucher promo code application.
- **Digital Admission Pass & QR Code**:
  - Gold-foil digital admission pass with scannable QR code.
  - Downloadable pass simulation and storage in Customer Dashboard.
- **Customer Dashboard (My Bookings)**:
  - Filter and view active movie tickets and private event reservations.
  - Digital Ticket modal popup with entrance barcodes.

---

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS + Custom Gold Glassmorphism & Glow Effects
- **Routing**: React Router v7
- **Icons**: Lucide React
- **Celebration Animations**: Canvas Confetti
- **Typography**: Cinzel (Serif luxury display), Playfair Display, Inter, Plus Jakarta Sans

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
git clone https://github.com/Dhivakar62/movie-ticket-.git
cd movie-ticket-
npm install
```

### Development Server

```bash
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
npm run build
npm run preview
```
